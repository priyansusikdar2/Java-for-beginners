# ☕ Beginner Java Programs

A collection of beginner-friendly Java programs to help students learn the fundamentals of Java programming. The repository includes simple, well-organized examples covering core Java concepts.

## 📚 Topics
- Java Basics
- Control Statements
- Loops
- Arrays
- Strings
- Methods
- Object-Oriented Programming (OOP)
- Exception Handling
- File Handling
- Pattern Programs

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/beginner-java-programs.git
cd beginner-java-programs
javac FileName.java
java FileName
```

## 🎯 Who Is This For?
- Beginners learning Java
- College students
- Coding practice
